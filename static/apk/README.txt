Put the Android APK from PWABuilder in this folder with the exact name:

    otakul.apk

It is then served at:

    https://otakul.co/static/apk/otakul.apk

The mobile install banner on the site links to that URL, so share this
link anywhere:  https://otakul.co/static/apk/otakul.apk

To update the app later: download a new package from PWABuilder, replace
this file with the same name, push, and redeploy — the banner keeps
working with no code changes.
